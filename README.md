## 폴더 구성
실행 영역별 롤이 서로 안 부딪히게 폴더 번호를 미리 예약해둠 — 새 폴더 만들 때 아래 표부터 확인.

| 번호 | 폴더 | 용도 |
| --- | --- | --- |
| 00 | `00.WBS` | 진행 관리(일정·체크포인트·회의록) |
| 10 | `10.PLANNING` | 기획 문서(시장조사·킥오프·백로그·발표전략) |
| 20 | `20.ARCHITECTURE` | 기술 설계·확정 스펙 |
| 30 | `30.DATA` | 가상 데이터 설계문서 + 생성 스크립트 |
| 40 | `40.PIPELINE` | 데이터·인프라 롤 — Data Factory, Dataverse 스키마·Security Role |
| 50 | `50.DATABRICKS` | ML·모델링 롤 — Databricks 노트북, risk_score, 예측 결과 |
| 60 | `60.RAG` | RAG·자동화 롤 — Power Automate, Teams Adaptive Card |
| 70 | `70.FRONT` | 대시보드·프론트 롤 — React 대시보드 소스코드 |
| 80 | `80.PRESENTATION` | 최종 발표 슬라이드·시연 스크립트 |
| 90 | `90.모두의창업` | 모두의창업 2기 지원(학교 프로젝트와 별개 트랙) |

> 40/50/60/70/80은 각 롤 담당자가 실제 코드·산출물을 만들면서 채우는 실행 폴더 — [[04. Week 0-3 실행 계획 & 동기화 체크포인트]]의 영역 구분과 번호를 그대로 맞춤. 아직 안 쓰는 번호는 없음 — 다음 대역이 필요하면 010/020처럼 3자리로 바꾸지 말고, 비어있는 10단위(현재는 없음, 다 씀) 안에서 성격이 겹치는 폴더끼리 소분류로 합치는 쪽을 먼저 검토.
