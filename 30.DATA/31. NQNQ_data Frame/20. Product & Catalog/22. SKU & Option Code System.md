## 🔢 SKU 코드 체계
> **2026.09 개편**: 체형코드(STR/WAV/NAT)는 실제로 다른 상품을 만드는 값이 아니라 스타일링 태그로 바뀌어서 **TOP/PNT/OUT/DRS는 코드에서 그 자리를 뺐다**. CLR은 톤코드(WRM/COOL/MUT)가 실제 염색 색상을 바꾸는 진짜 제품 차원이라 그대로 유지. 근거: [[27. 체형태그·사이즈 확장 개편안 (블랙업 벤치마크)]].

| 카테고리 | 형식 |
| --- | --- |
| TOP / PNT / OUT / DRS | `[브랜드]-[카테고리]-[일련번호]-[사이즈]-[컬러]` |
| CLR | `[브랜드]-[카테고리]-[톤코드]-[일련번호]-[사이즈]-[컬러]` |
| ACC | `[브랜드]-[카테고리]-[아이템종류]-[일련번호]-[사이즈]-[컬러]` |

예시:
- `NQ-TOP-001-M-BLK` (스퀘어-V넥 기본티, M, 블랙 — 체형 추천 태그는 product 속성 `recommended_body_types=STR,WAV,NAT`로 별도 관리)
- `NQ-PNT-001-S-BLK` (5-Length 슬랙스, S, 블랙)
- `NQ-CLR-WRM-001-M-CRM` (퍼스널컬러 웜톤 베이직, M, 크림 — 톤코드는 그대로 코드에 남음)

| 자리 | 의미 | 값 목록 |
| --- | --- | --- |
| 브랜드 | 고정값 | NQ |
| 카테고리 | 대분류 | TOP / PNT(PANTS) / CLR(COLOR 베이직 라인) / OUT / ACC / DRS |
| 톤코드 (CLR 전용) | 실제 염색 색상 계열 | WRM(웜)·COOL(쿨)·MUT(뮤트) |
| 아이템종류 (ACC 전용) | 액세서리 종류 | BAG·BLT·SCF·CAP·PCH |
| 일련번호 | 스타일 고유번호 | 001~999 |
| 사이즈 | 카테고리별 사이즈표 | 아래 참고 |
| 컬러 | 컬러 코드 | 아래 참고 |

## 🏷️ 라인 타입 (2026.08 추가)
[[21. Core Product Categories]]의 트렌드 캡슐 도입에 따라 스타일마다 라인 타입을 구분한다 (SKU 코드 자체는 안 바뀌고, PRODUCT 엔터티의 별도 속성으로 관리 — [[71. Entity Definitions & Data Dictionary]] 참고).

| 라인 타입 | 설명 | 운영 방식 |
| --- | --- | --- |
| 베이직(BASIC) | 상시 판매, 브랜드 핵심 정체성 | 시즌 제한 없이 지속 판매 |
| 트렌드캡슐(TREND) | 시즌 트렌드 반영, 한정 판매 | 1~2시즌 후 단종 또는 베이직 승격 |

## 📏 사이즈 체계
> 2026.09 개편: TOP/PNT는 XS~4XL 8단계로 확장(사이즈 다양성 차별화 포인트, [[27. 체형태그·사이즈 확장 개편안 (블랙업 벤치마크)]] 참고). OUT/DRS/CLR은 기존 3단계 유지 — 사이즈 다양성 검증을 우선 상의·하의로 좁혀서 진행.

| 카테고리              | 사이즈 코드                                      | 기준                                            |
| ----------------- | ------------------------------------------- | --------------------------------------------- |
| TOP / PNT         | XS / S / M / L / XL / 2XL / 3XL / 4XL (8단계) | 잠정 배분 비율은 27번 문서 참고 — 실측 없는 가정치, 테스트판매로 보정 예정 |
| OUT / DRS / COLOR | S / M / L                                   | 키 150~159 / 160~169 / 170~179cm               |

## 🎨 컬러 코드
> 2026.09 개편: TOP/PNT는 "뉴트럴 코어(전 디자인 공통) + 포인트 컬러(HERO 디자인 1개 한정)" 규칙 적용 — 블랙업 실측 컬러 비율 근거는 [[27. 체형태그·사이즈 확장 개편안 (블랙업 벤치마크)]] 1-2절.

| 카테고리 | 코어 컬러 (전 디자인) | 포인트 컬러 (HERO 디자인 한정) |
| --- | --- | --- |
| TOP | BLK(블랙) / WHT(화이트) / GRY(그레이) / NVY(네이비) | ORC(오키드) / SKB(하늘색) / LYL(연노랑) |
| PNT | BLK(블랙) / GRY(그레이) / BEG(베이지) | KHK(카키) / NVY(네이비) |
| COLOR 베이직 | CRM(크림, 웜) / ASH(애쉬그레이, 뮤트) / IVR(아이보리, 쿨) | (변경 없음) |
| OUT / DRS / ACC | 기존과 동일 (변경 없음, [[21. Core Product Categories]] 참고) | - |

## 🏷️ 인기도 티어 (2026.08 추가) — 롱테일 반영
디자인마다 판매 가중치를 다르게 부여해, 모든 SKU가 균등하게 잘 팔리는 비현실적 구조 대신 **몇 개 히트작이 대부분을 이끄는 롱테일**을 만든다.

| 티어 | 가중치 | 의미 |
| --- | --- | --- |
| HERO | 3.0x | 카테고리 대표 스테디셀러 (예: 스퀘어라인 기본티) |
| STEADY | 1.0x | 꾸준히 팔리는 보급형 디자인 |
| NICHE | 0.3x | 소량 판매, 취향 세분화용 디자인 |

**검증 결과**(실데이터, [[02. Project WBS & Roadmap]]): HERO 평균 7,740개/년 · STEADY 2,546개 · NICHE 858개 — 설계 비율(3:1:0.3=10:3.3:1)과 거의 일치.
