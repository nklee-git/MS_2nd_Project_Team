**논의 내용**:
- **임현제** — RAG를 활용해, 일정 시간 사람 개입 없이 과거 최적값 기반으로 발주까지 진행하는 프로세스를 제안. 관리자 부재·응답 불가 상황에 대비해 완전자동화는 아니더라도 일부를 대신할 수 있는 안전장치 개념. 다만 이전 발주 이력(사람이 몇 건 주문했는지) 데이터가 필요한데 현재 없음 — 임의 생성이 필요할 수 있음.
- **최민** — 완전자동화는 지양(B2B 특성상 "도움이 되는 모듈" 정도가 적절). 기능부터 붙이기보다 시나리오를 먼저 완성한 뒤 기능을 전개하는 순서를 제안. 추가로, 데이터를 실시간 생성하고 저장 한계치를 넘으면 오래된 데이터를 지우고 임의값으로 채우는 모듈 아이디어도 제시.

**결정사항**: Dataverse를 실제로 한 번 사용해보고, IaC(Infrastructure as Code) 지원 여부를 확인 — 가능하면 위 아이디어들의 구현 경로가 될 수 있음.
